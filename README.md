# Cisse DAO Voting

A decentralized voting application built for the IOPn Builders Program.

## Features

- DAO Proposal Display
- YES / NO Voting System
- Live Vote Counter
- Smart Contract Prototype
- Responsive User Interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Solidity

## Project Goal

To demonstrate a simple decentralized governance system where community members can vote on proposals.
